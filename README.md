ProjectHub

ProjectHub is a developer-focused platform built to help creators showcase, manage, and share their projects in one clean and modern space. Instead of scattered links and messy portfolios, ProjectHub gives developers a single place that truly represents their work, creativity, and technical skills.

Key Highlights
-Built specially for developers and student creators
-Clean, modern UI that focuses on projects, not distractions
-Supports everything from small experiments to full-stack apps
-Easy to use, fast, and visually engaging

Tech Stack : 
ProjectHub uses a carefully chosen tech stack to ensure performance, scalability, and a smooth developer experience. Each tool was selected to make development faster, safer, and more enjoyable.

Technologies Used
-SvelteKit & Svelte 5 – Fast, lightweight framework with built-in frontend and backend support
-TypeScript – Adds type safety and helps reduce bugs early
-Three.js – Used for interactive 3D visuals on the landing page
-PostgreSQL – Reliable and powerful relational database
-Drizzle ORM – Type-safe database operations using TypeScript
-Bcrypt – Secure password hashing
-Zod – Validates and protects incoming API data


How to Run ProjectHub Locally
Running ProjectHub on your system is simple and beginner-friendly. Just follow the steps below in order.

Steps to Run
-Install Node.js (v18+)
-Install and run PostgreSQL locally
-Run npm install to install dependencies
-Create a .env file using .env.example
-Update DATABASE_URL with your local database details
-Run npm run db:push to set up database tables
-(Optional) Run npm run db:seed for sample data
-Start the app using npm run dev
